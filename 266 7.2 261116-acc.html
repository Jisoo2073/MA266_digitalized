Sec 7.2 Transformation of initial value problems

Goal: use Laplace transform to solve initial equation

Key observation:

\[ \begin{aligned} \mathcal{L}\{f'(t)\}(s) &= \int_0^\infty e^{-st} f'(t)\,dt \\ &= e^{-st} f(t) \Big|_0^\infty + s \int_0^\infty e^{-st} f(t)\,dt \\ &= \lim_{b \to \infty} e^{-sb} f(b) - f(0) + s \mathcal{L}\{f(t)\} \\ &\stackrel{\text{When } b \text{ large enough}}{=} s F(s) - f(0) \end{aligned} \]

Remark: in this course, \( \lim_{b \to \infty} e^{-sb} f(b) = 0 \)

Laplace Transform of Higher Derivatives

For \( f''(t) \), \( g = f' \)

\[ \begin{aligned} \mathcal{L}\{f''(t)\}(s) &= \mathcal{L}\{g'(t)\}(s) = s\mathcal{L}\{g(t)\}(s) - g(0) \\ &= s\mathcal{L}\{f'(t)\} - f'(0) \\ &= s(s\mathcal{L}\{f(t)\} - f(0)) - f'(0) \\ &= s^2 F(s) - s f(0) - f'(0) \end{aligned} \]

Generally

\[ \mathcal{L}\{f^{(n)}(t)\}(s) = s^n F(s) - s^{n-1} f(0) - \dots - s f^{(n-2)}(0) - f^{(n-1)}(0) \]

An alternate way to compute the inverse Laplace.

\[ F(s) = \mathcal{L}\{f(t)\} \]\[ \mathcal{L}^{-1}\left\{ \frac{F(s)}{s} \right\} = \int_{0}^{t} f(u) \, du . \]

eg. \( F(s) = \frac{1}{s(s^2 - 9)} \)

\[ \mathcal{L}^{-1}\left\{ \frac{1}{s(s^2 - 9)} \right\} = \frac{1}{6} \int_{0}^{t} e^{3u} - e^{-3u} \, du \]

Example 1: Solving a Second-Order Differential Equation

Given the differential equation:

\( x'' - 2x' - 3x = 0 \), with initial conditions \( x(0) = -2 \) and \( x'(0) = 6 \).

Applying the Laplace transform \( \mathcal{L} \):

\[ \begin{aligned} \mathcal{L}\{x''(t)\} - 2\mathcal{L}\{x'(t)\} - 3\mathcal{L}\{x(t)\} &= 0 \\ s^2 \mathcal{L}\{x\} - s x(0) - x'(0) - 2(s \mathcal{L}\{x\} - x(0)) - 3 \mathcal{L}\{x\} &= 0 \\ (s^2 - 2s - 3) \mathcal{L}\{x\} - s x(0) - x'(0) + 2x(0) &= 0 \\ (s^2 - 2s - 3) \mathcal{L}\{x\} &= -2s + 10 \\ \mathcal{L}\{x\} = \frac{-2s + 10}{s^2 - 2s - 3} &= \frac{-2s + 10}{(s - 3)(s + 1)} \\ &= \frac{A}{s - 3} + \frac{B}{s + 1} \end{aligned} \]

Solving for partial fraction coefficients:

\[ \begin{cases} A + B = -2 \\ A - 3B = 10 \end{cases} \implies \begin{aligned} B &= -3 \\ A &= 1 \end{aligned} \]

Substituting back:

\[ \mathcal{L}\{x\} = \frac{1}{s - 3} + \frac{-3}{s + 1} \]

Taking the inverse Laplace transform:

\[ x = \mathcal{L}^{-1} \left\{ \frac{1}{s - 3} + \frac{-3}{s + 1} \right\} = e^{3t} - 3e^{-t} \]

eg 2. Second-Order ODE with Laplace Transform

\( x'' + x = 5\cos 4t \), \( x(0) = 1 \), \( x'(0) = 0 \)

\[ \begin{aligned} \mathcal{L}\{x''\} + \mathcal{L}\{x\} &= \mathcal{L}\{5\cos 4t\} \\ s^2\mathcal{L}\{x\} - sx(0) - x'(0) + \mathcal{L}\{x\} &= \frac{5s}{s^2 + 4^2} \\ (s^2 + 1)\mathcal{L}\{x\} &= \frac{5s}{s^2 + 16} + s \\ \mathcal{L}\{x\} &= \frac{5s}{(s^2 + 1)(s^2 + 16)} + \frac{s}{s^2 + 1} \end{aligned} \]

Partial fraction decomposition:

\[ \frac{5s}{(s^2 + 1)(s^2 + 4^2)} = \frac{A_1 s + A_2}{s^2 + 1} + \frac{B_1 s + B_2}{s^2 + 16} \]\[ A_1 s^3 + 16A_1 s + A_2 s^2 + 16A_2 + B_1 s^3 + B_1 s + B_2 s^2 + B_2 \]
\[ \begin{cases} A_1 + B_1 = 0 \\ A_2 + B_2 = 0 \\ 16A_1 + B_1 = 5 \\ 16A_2 + B_2 = 0 \end{cases} \]
\[ \begin{aligned} A_1 &= \frac{1}{3} \\ B_1 &= -\frac{1}{3} \end{aligned} \]
\[ \begin{aligned} \mathcal{L}\{x\} &= \frac{1}{3} \frac{s}{s^2 + 1} - \frac{1}{3} \frac{s}{s^2 + 16} + \frac{s}{s^2 + 1} \\ &= \frac{4}{3} \frac{s}{s^2 + 1} - \frac{1}{3} \frac{s}{s^2 + 16} \end{aligned} \]\[ \begin{aligned} x &= \frac{4}{3} \mathcal{L}^{-1}\left\{ \frac{s}{s^2 + 1} \right\} - \frac{1}{3} \mathcal{L}^{-1}\left\{ \frac{s}{s^2 + 16} \right\} \\ &= \frac{4}{3}\cos t - \frac{1}{3}\cos 4t \end{aligned} \]

Example 3: Solving a System of Differential Equations

Given the system of differential equations with initial conditions:

\[ \begin{cases} x'' + 2y' + x = 0 \\ x' - y' + y = 0 \end{cases} \quad \begin{cases} x(0) = 0 \\ y(0) = 1 \end{cases} \]

Applying the Laplace transform to both equations:

\[ \begin{cases} \mathcal{L}\{x''\} + 2\mathcal{L}\{y'\} + \mathcal{L}\{x\} = 0 \\ \mathcal{L}\{x'\} - \mathcal{L}\{y'\} + \mathcal{L}\{y\} = 0 \end{cases} \]

Substituting the initial conditions:

\[ \begin{cases} s^2\mathcal{L}\{x\} - sx(0) - x'(0) + 2(s\mathcal{L}\{y\} - y(0)) + \mathcal{L}\{x\} = 0 \\ s\mathcal{L}\{x\} - x(0) - (s\mathcal{L}\{y\} - y(0)) + \mathcal{L}\{y\} = 0 \end{cases} \]

Simplifying the system:

\[ \begin{aligned} (s^2+1)\mathcal{L}\{x\} + 2s\mathcal{L}\{y\} &= 2 \\ s\mathcal{L}\{x\} + (1-s)\mathcal{L}\{y\} &= -1 \end{aligned} \]

Solving for \(\mathcal{L}\{x\}\) and \(\mathcal{L}\{y\}\):

\[ \mathcal{L}\{x\} = \frac{2(s-1) - 2s}{(s^2+1)(s-1) + 2s^2} = \frac{-2}{3s^2-1} = -\frac{2}{\sqrt{3}} \frac{\sqrt{3}/3}{s^2 - 1/3} \]
\[ \mathcal{L}\{y\} = \frac{2s + s^2 + 1}{3s^2 - 1} = \frac{3s^2+1}{3s^2-1} = \frac{s}{s^2-1/3} + \frac{1}{3} \frac{1}{s^2-1/3} \]

Taking the inverse Laplace transform to find the solutions:

\[ x(t) = -\frac{2}{\sqrt{3}} \sinh\left(\frac{t}{\sqrt{3}}\right) \]
\[ y(t) = \cosh\left(\frac{t}{\sqrt{3}}\right) + \frac{1}{\sqrt{3}} \sinh\left(\frac{t}{\sqrt{3}}\right) \]
